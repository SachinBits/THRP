🔧 PREPROCESSING MODULE DETAILS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CLAHE (Contrast Limited Adaptive Histogram Equalization):
  ├─ Purpose: Normalize lighting, defeat atmospheric haze
  ├─ Clip Limit: 2.0 (prevents over-enhancement)
  ├─ Tile Size: 8×8 blocks
  ├─ Process:
  │  1. Convert BGR → LAB color space
  │  2. Extract L (lightness) channel
  │  3. Apply CLAHE to L channel
  │  4. Reconstruct LAB → BGR
  └─ Output: Enhanced contrast image

Canny Edge Detection:
  ├─ Purpose: Extract structural features
  ├─ Threshold 1: 50 (lower edge threshold)
  ├─ Threshold 2: 150 (upper edge threshold)
  ├─ Pre-processing: Gaussian blur (5×5, σ=1.5)
  ├─ Process:
  │  1. Convert to grayscale
  │  2. Apply Gaussian blur
  │  3. Compute gradients
  │  4. Non-maximum suppression
  │  5. Double thresholding & edge tracking
  └─ Output: Binary edge map

Fusion Strategy:
  ├─ Weights: 70% CLAHE + 30% Edges
  ├─ Purpose: Emphasize geometry over camouflage
  ├─ Formula: fused = CLAHE × 0.7 + edges × 0.3
  └─ Output: Enhanced image ready for specialist

Benefits:
  ✓ Reduces lighting variations
  ✓ Defeats atmospheric haze
  ✓ Emphasizes aircraft silhouettes
  ✓ Reduces camouflage texture interference
  ✓ Improves aircraft feature extraction
