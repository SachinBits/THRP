✅ PHASE 6: PREPROCESSING MODULE

════════════════════════════════════════════════════════════════════════════════

[✅] CLAHE Implementation
     ├─ Color Space: LAB (optimal for CLAHE)
     ├─ Clip Limit: 2.0 (configurable)
     ├─ Tile Grid: 8×8 (configurable)
     ├─ Channel: L (Lightness) only
     ├─ Output: Enhanced BGR image
     ├─ Benefits:
     │  ├─ Lighting normalization
     │  ├─ Atmospheric haze removal
     │  └─ Local contrast preservation
     └─ Fail-safe: Works on grayscale too

[✅] Canny Edge Detection
     ├─ Lower Threshold: 50
     ├─ Upper Threshold: 150
     ├─ Pre-processing: Gaussian Blur (5×5, σ=1.5)
     ├─ Post-processing: Binary output
     ├─ Benefits:
     │  ├─ Structural feature extraction
     │  ├─ Aircraft silhouette emphasis
     │  └─ Camouflage texture reduction
     └─ Output: Binary edge map

[✅] Fusion Strategy
     ├─ CLAHE Weight: 70%
     ├─ Edge Weight: 30% (configurable)
     ├─ Method: Weighted additive blending
     ├─ Normalization: 0-255 range maintained
     ├─ Benefits:
     │  ├─ Geometry emphasis over texture
     │  ├─ Camouflage resilience
     │  └─ Improved specialist accuracy
     └─ Output: Enhanced ROI image
